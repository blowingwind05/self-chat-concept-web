# 一个只和自己聊天的 App · 项目构想

GitHub Pages 预览地址：[https://blowingwind05.github.io/self-chat-concept-web/](https://blowingwind05.github.io/self-chat-concept-web/)。

源码入口：`dist/index.html`。仓库内可直接浏览完整 HTML、CSS、JavaScript 与媒体文件。

这是原生 HTML、CSS、JavaScript 制作的项目设想展示页，无框架、无安装步骤、无外部字体或 CDN 依赖。

## 打开

双击 dist/index.html 即可查看。也可以把 dist 目录交给任意静态网页服务器。

## 视频

首屏后直接嵌入完整的 1 分 48 秒短片，保留进度、声音、重播与全屏控制。默认不自动播放，点击播放后有声音；滚出视频区域时暂停。音轨、图片与脚本随网页一起保存，可以离线使用。

短片在同一画面内展示消息进入云端、AI 处理与六种整理结果；开场与故事、聊天窗口与流程图之间有连续转场。

视频旁标注「前端实时渲染 · 无视频流量」。画面在浏览器内绘制，未使用视频文件或视频流。

标题只描述这个项目是什么，项目尚未命名。更新了第一人称故事标题、多电脑登录与记录留存的使用不便；身份验证和网络安全为安全段落的重点。原有四幕滚动核心理念、首屏浮卡、动态开关、手机阅读方式均保留。

## 文件

- dist/index.html：正文、原案例子与 SVG 图标。
- dist/styles.css：视觉排版和四幕滚动转场。
- dist/reading.css：正文可读性、移动端连续阅读布局。
- dist/updates.css：视频嵌入与本轮排版调整。
- dist/film/：完整播放器、音轨、图片与音乐许可。
- dist/app.js：滚动进度、四幕切换、进场动画及动态开关。
- dist/hero-words.js：首屏词语汇聚，沿不同路径进入聊天输入区。
- dist/mobile-core.css：手机核心理念的四幕固定舞台、连续阅读布局与动画样式。
- dist/mobile-core.js：手机核心理念的阶段切换、汇聚与传输动效，以及离屏暂停和重播。
- dist/assets/reference-architecture.png：从用户提供的原案中提取的建筑摄影示例。
- dist/assets/favicon.svg：网页图标。

## 展示方式

桌面端的核心理念依次呈现九种用途、同一条聊天时间线、云端与 AI 的分工、六种信息视图。后两幕保留缩小的原始聊天记录。

灵感来源章节在所有双栏宽度下限制标题栏为 220–420px，正文使用剩余空间，栏间距随窗口连续调整。整体内容宽度上限为 1600px；760px 及以下保持单栏阅读。

六种信息视图直接展示前文消息整理后的内容：电影与番剧清单、提醒时间、摄影素材、单词与讲稿、生活记录，以及按描述找回同一张照片的检索示例。下方两张提取卡依次高亮原消息、展开箭头、显示结果。

常见手机在视口宽度不小于 360px、高度不小于 740px 时，使用随滚动展开的四幕固定舞台：用途汇聚、消息逐条出现、云端与 AI 处理，以及整理结果展开。较矮或较窄的手机使用连续阅读布局，保留同样的动作，不会退回静态展示；较矮横屏也保持连续阅读。

手机核心动画离开视野后停止，重新进入时可以再次播放。右上角关闭动态或启用系统“减少动态效果”时，使用完整可读的静态布局。没有 JavaScript 时仍能阅读全部内容。

滚动进场、提取示例和路线图可以在离开视野后再次触发；返回首屏也会重播标题与消息的入场。核心四幕保持可逆，循环浮动与传输动画保留离屏暂停。

首屏混合呈现 60 个用途、作品名、文件名和单词，完整包含参考版本的 24 个词。桌面端同时有约 40 条词流，经八类浅弧、斜线和接力路径汇入输入区，左侧也充分参与。经过标题与正文时降低透明度，沿路径接近匀速移动，在输入区末端缩小并分流；右侧窗口、浮卡和圆环整组缩小。离开首屏或关闭动态会停止，返回后重新播放。所有绘制与资源均在本地完成。

这是一份项目构想展示，未实现登录、真实云端存储、AI 处理或文件传输，也不收集用户输入。
